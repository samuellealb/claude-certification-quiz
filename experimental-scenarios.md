# Test Scenarios

## 1. Airline Disruption Dispatch

Northwind Regional, an airline, coordinates rebooking, gate changes, and crew relief during weather disruptions; its agent must manage tool loops, continuation, and context.

## 2. Fraud Investigation Coordinator

Meridian Trust, a bank, routes suspicious-transaction reviews through specialist subagents and human escalation while enforcing AML checks and protecting customer data.

## 3. Warehouse Inventory Assistant

Halverson Supply, a retailer, uses a warehouse assistant to check location-specific stock, track shipments, and reserve inventory; clear tool boundaries prevent misroutes and unintended reservations.

## 4. Ticketing and Data Warehouse Integration

Lumen Labs' platform team connects Claude Code to a ticket tracker and release-metrics warehouse, requiring reliable errors, secure shared credentials, and precise code-search and rename operations.

## 5. Consulting Configuration Standards

Brightline Consulting's consultants work across client repositories with different coding conventions; their Claude Code guidance needs clear precedence and path-scoped rules without leaking personal settings into shared work.

## 6. Studio Automation Pipeline

Kestrel Interactive, a game studio, uses Claude Code for headless CI, parallel feature branches, and unfamiliar-system migrations, with deterministic automation and separate test and reporting outputs.

## 7. Clinical Trial Data Extraction

Verity Clinical Data, a health-data vendor, extracts structured trial records from scanned forms; its workflow must handle missing data, enforce structured responses, and escalate repeated validation failures.

## 8. Marketplace Listing Reviews

Tidemark Marketplace reviews listings for policy violations in real time and at batch scale, requiring consistent severity decisions, independent appeals, and reliable result-to-listing correlation.

## 9. Cross-Border Database Migration

Calder Freight's data team audits and migrates many microservice databases over several days, preserving precise context, reviewing broad inputs carefully, and limiting oversized tool results.

## 10. Mortgage Prequalification

Rockford Savings, a regional lender, automates mortgage prequalification across varied income and credit evidence, monitoring cohort performance and escalating conflicts, tool failures, and ambiguous cases.

## 11. Regulated Agent Delivery

A team is taking a regulated support agent from platform selection through build, evaluation, and deployment. They need reusable delivery assets, explicit security boundaries, and clear rules for managed services and SDK configuration.

## 12. Enterprise MCP Knowledge Gateway

An enterprise MCP server exposes policy documents, reusable prompts, and approved operational tools. Its clients need schema-safe calls, deliberate tool visibility and permissions, and transport choices that match where the server runs.

## 13. Developer Productivity Platform

A platform engineering team packages Claude Code settings, plugins, Skills, and MCP integrations for developers. Central standards, authentication, command discovery, cache boundaries, and runtime limits must work across local and hosted environments.

## 14. Claims Processing API

A claims API returns structured classifications while balancing response quality, latency, and cost. The team uses schema reuse and targeted reasoning effort without corrupting the model's required conversation state.

## 15. Enterprise Data Platform with Federated Queries

An analytics platform retrieves data from stable and changing sources for support and operations. It needs the right retrieval route, secure handling of untrusted content, and caching that improves cost without serving stale policy.
